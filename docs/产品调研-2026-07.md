# 产品调研:AI 写作类竞品与落笔的差距(2026-07)

> 调研方式:网络检索(秘塔写作猫官网及测评、Notion AI 官方文档、零克查词/红薯编辑器官网、壹伴测评、AIbase 工具库)。
> 结论驱动的功能改动见同日提交:编辑深度三件套 + 发布前检查。

## 竞品能力对照

| 竞品 | 定位 | 核心能力 | 对落笔的启示 |
|---|---|---|---|
| 秘塔写作猫 | 中文写作辅助平台 | 智能**续写**、选中**改写润色**、实时**纠错校对**、多人协作、Word 插件 | 落笔快捷操作原先只有全文级,缺「续写」与「选中局部改写」 |
| Notion AI | 文档工作台 AI | **划词 → 对选区执行 AI 操作**(改进写作/简化/换语气/翻译),学习个人风格 | 划词改写是行业标准交互;「风格学习」落笔已用 Skills 机制部分覆盖 |
| 零克查词 / 红薯编辑器 | 发布前检测(独立付费品类) | 小红书/公众号/抖音**违禁词检测**、广告法极限词、防限流 | 落笔定位「写完即发」,原先缺发布前检查这一环 |
| 壹伴 | 公众号浏览器插件 | 「选题→写稿→排版→发布」全流程、AI 排版、数据反馈 | 补上检查环节后,落笔覆盖 写→检→(图文)→发 的主链路 |
| 光速写作 | 学生/职场写作 | 大纲生成、全文生成、改写/续写/扩写、多端云存 | 续写是标配;大纲生成、云同步可作后续方向 |
| 火龙果写作 | 校对工具 | 错别字/语法检查、降重 | 校对并入发布前检查;降重非落笔目标场景 |

## 结论

落笔的「生成」环节(平台适配/语气/技能/标题/图文卡片)已成型,差距集中在:

1. **编辑深度**——生成后的改稿体验:选中一段局部改写(而不是每次全文重写)、AI 改坏可撤销、顺着写下去(续写)
2. **发布前一公里**——违禁词风险/错别字检查。竞品作为独立产品收费,落笔用「AI 检查 + 一键应用建议」的方式并入主流程,是差异化机会

## 已落地(2026-07-14)

- 快捷操作新增**续写**(追加式,QUICK_ACTIONS 增加 mode 字段)
- **选中局部改写**:正文选中后,换写法/扩写/精简/润色只作用于选中段,AI 结果带上下文衔接要求,替换回原位
- **AI 操作撤销**:每次 AI 修改正文前压栈(上限 10),操作条「↩ 撤销」回退
- **发布前检查**:AI 按当前平台输出 JSON 报告(安全分/总评/问题列表:风险・错别字・存疑,含严重度),每条可一键应用建议或忽略;正文再修改后报告标记过期
- 修复内置通道 `max_tokens` 1000 → 2000(公众号长文截断隐患)

## 第二批已落地(2026-07-14)

- **流式输出(SSE)**:所有竞品标配,原先整篇干等是体验差距最明显的一处。正文类生成改为逐字落进编辑器;两种协议(Anthropic `content_block_delta` / OpenAI `choices[].delta.content`)都支持,服务端不支持流式时自动退回一次性返回,设置页可关闭
- **大纲先行**(光速写作模式):「先列大纲」→ AI 出 4-6 小节 → 面板里可改标题/改说明/调序/增删 → 「按大纲成文」。长文不再一把梭,结构可控

## 候选后续方向(按调研排序,未做)

2. 双模型对比出稿
3. 云同步 / 多端(桌面端已有本地持久化基础)

5. 大纲逐节生成:按小节分别调用,超长文不受 max_tokens 限制
